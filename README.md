# 2026-04-13
Recipe Dashboard

A responsive recipe search and browsing application that allows users to search for recipes via external API, view recipe details and explore results in a structured UI.

Features:
-Search Recipes by name
-Display recipe results in a responsiv card layout
-Detailed recipe view page (ingredients & instructions)
-Error handling for failed requests 
-Mobile friendly responsive design

Tech Stack:
Frontend: React
Routing: React Router
API: The MealDB
Styling: CSS
